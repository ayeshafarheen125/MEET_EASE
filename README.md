MeetEase

An AI-powered meeting notes and transcript management system with automated backend processing and a modern frontend dashboard.

---

🚀 Features

* **Meeting Processing**: Upload audio/video recordings or text transcripts for automated analysis.
* **Interactive Dashboard**: View, organize, and inspect meeting notes and action items.
* **Smart Summaries & AI Chat**: Built-in chatbot interface to query specific meeting details.

---

🛠️ Tech Stack

* **Frontend**: Next.js 14, React, TypeScript, Tailwind CSS, Shadcn UI
* **Backend**: Python, Flask / FastAPI, Jupyter Notebooks
